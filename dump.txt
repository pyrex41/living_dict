Anthropic never published a single post titled “agent graphs.” What people mean by that phrase is a stack of their actual writing — plus the way Claude Code turned those ideas into practice.

What Anthropic actually said
Building Effective Agents (Dec 2024) draws the hard line:

Workflows — LLMs and tools orchestrated through predefined code paths
Agents — LLMs that dynamically direct their own process and tool use
Five workflow shapes sit under that:

Pattern	Shape
Prompt chaining	Fixed sequence with gates
Routing	Classify → specialized path
Parallelization	Fan-out (sectioning or voting)
Orchestrator–workers	Lead decomposes, workers run, lead synthesizes
Evaluator–optimizer	Generate → critique → loop
Multi-agent research system (Jun 2025) is the production version of orchestrator–workers: a lead agent plans, spawns parallel subagents, merges results. ~90% better on their internal research eval than a single agent — and ~15× the tokens.

Multi-agent coordination patterns (Apr 2026) names five coordination styles: generator–verifier, orchestrator–subagent, agent teams, message bus, shared state.

The 2026 “graph engineering” discourse is a reframe of all of that:

Nodes = specialized agents (own prompt, tools, context)
Edges = routing (fan-out, handoff, conditional, loop)
Shared state = results, memory, files flowing between nodes
Claude Code’s practical move: the main agent writes a script that is the graph, then the runtime executes that script. Topology becomes code.

How Living Dictionary maps onto it
Your harness is not a loose analogy. It is a very literal implementation of the same topology, with the intelligence placed differently.

Anthropic’s strongest advice is: prefer explicit code paths when you can. Living Dictionary takes that to the extreme.

Orchestrator plans	Shen classifies the goal, pattern-matches the world

Runtime executes the script	Forth machine runs the words
Nodes = subagents / steps	Nodes = words (primitives, tools, colon defs)
Edges = call order, branches, loops	Edges = concatenation, IF/ELSE/THEN, DO/LOOP
OBSERVE
THINK

( patch applied )

That is not “an agent thinking out loud.” That is a DAG of tool nodes with a verification edge, written in a language whose only job is composition. Anthropic’s shared-state pattern: agents read/write a persistent store; work emerges from what’s already there.

Anthropic’s later patterns (agent teams, message bus, shared state) map cleanly onto the OpenResty host you sketched:
